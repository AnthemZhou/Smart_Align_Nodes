# Smart Align Nodes v1.0.0

## 中文

此版本将节点移动吸附和 Command/Ctrl + O 自动排列一起发布。

- **自动排列**：选中节点后按 macOS **Command + O** / Windows、Linux **Ctrl + O**，或点击侧栏“排列选中节点”。结合连接顺序、节点边缘和插口整理分支。
- **Frame**：选中框会递归包含全部内部节点和嵌套框；多个框在各自原位置附近整理。
- **转接点**：复用已有串联转接点，按需增加绕行点并清理多余自动点，保留逻辑连接，支持撤销与取消回滚。
- **偏好设置**：可调自动布局横向间距（24–400），中英文界面、提示与工具提示，突出显示平台快捷键。
- **移动吸附**：支持 G、拖动、新建与复制节点，使用可见边界和带占用检测的画布网格。
- **性能**：同步写入节点和连线；几何未变化时跳过重复求解，只更新实际发生变化的位置与路径。

### 安装

下载附件 **Smart_Align_Nodes_v1.0.0.zip**，在 Blender 的“编辑 → 偏好设置 → 插件”中从磁盘安装并启用。不要使用 GitHub 自动生成的 Source code ZIP。覆盖旧版本后，保存工作并重启 Blender 以加载新代码。

### 验证

发布前重新通过 105 项 Python 单元测试、Blender 5.2.2 的 12 项界面布局回归，以及两轮插件注册/卸载检查（快捷键、原生创建入口、Node Console 替身桥接与定时器清理）。

### 已知限制

自动布局的插口和曲线坐标使用估算。局部紧凑回退可能挤掉已有中间走线通道，产生多余的顶部绕行，同时丢失整列边缘对齐；最新反馈的此项问题尚未修复。复杂图不保证零交叉或完全无遮挡。

插件声明最低 Blender 4.0；主要实测环境为 macOS / Blender 5.2.2，Windows/Linux、其他版本及自定义节点尚未全面验证。Node Console 桥接使用替身测试，不能视为真实插件交互验收。

## English

This release brings live node snapping and Command/Ctrl + O automatic arrangement together.

- **Arrange** selected nodes with **Command + O** on macOS / **Ctrl + O** on Windows and Linux, or the sidebar action. Organize branches using connections, card edges and sockets.
- **Frames** recursively include all descendants when selected. Multiple selected Frames arrange their contents near their original locations.
- **Reroutes** reuse existing serial points, add bends when needed and remove surplus generated points while preserving logical links, undo and cancellation rollback.
- **Preferences** include adjustable horizontal layout spacing (24–400), English and Simplified Chinese UI/reports/tooltips, and a prominent platform shortcut.
- **Live snapping** supports G, dragging, creation and duplication, using visible boundaries and an occupancy-aware canvas grid.
- **Performance** improvements apply cards and wires together, skip repeated solving when geometry is unchanged, and avoid unnecessary position/link writes.

### Install

Download the **Smart_Align_Nodes_v1.0.0.zip** asset, install it from disk under Blender's **Edit → Preferences → Add-ons**, and enable the add-on. Do not use GitHub's generated Source code ZIP. After replacing an older version, save your work and restart Blender to load the update.

### Validation

Release checks passed: 105 Python unit tests, 12 Blender 5.2.2 GUI layout cases, and two registration/unregistration cycles covering keymaps, native creation hooks, the Node Console stub bridge and timer cleanup.

### Known limitations

Socket locations and wire shapes are estimates. Compact fallback can close an existing central wire corridor, introduce unnecessary overhead reroutes and lose column-edge alignment. The latest reported case remains unresolved in this release. Complex graphs are not guaranteed to have zero crossings or obstructions.

The declared minimum is Blender 4.0; the primary tested environment is macOS / Blender 5.2.2. Windows/Linux, other versions and custom nodes have not been comprehensively verified. The Node Console bridge test uses a stub, not the installed product's complete interaction flow.
