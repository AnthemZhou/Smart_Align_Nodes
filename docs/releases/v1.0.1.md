# Smart Align Nodes v1.0.1

## 中文

修复选中包含多个子 Frame 的外层框后，节点小幅移动反而破坏已有对齐和间距的问题。

- 结构排列和受限回退保留已有的节点行、同级列和连续等间距。
- 受限回退保持原左上范围，避免连线缩短一点却把整行或分组拆散；邻接节点可以并入已有对齐行。
- 区分同级列与串联计算阶段，原本纵向堆叠的串联节点仍可排成从左到右。
- “Estimate merge distance” 的实测最大位移由约 141.76 降为 34.40 个画布单位，三个 Frame 保持原位，末端节点并入原有行。

### 验证

108 项单元测试、12 项 Blender 5.2.2 界面布局检查、3 项 Frame 选择回归及插件注册/卸载检查通过。当前 617 节点树的副本连续执行 10 次没有累积位移，撤销和重做误差为 0，逻辑连接、父级、可见选区和框外节点位置保持不变。

### 安装与已知限制

下载 **Smart_Align_Nodes_v1.0.1.zip**，在 Blender 插件偏好设置中从磁盘安装并启用。手动覆盖旧版后，保存工作并重启 Blender 以加载更新。

此补丁针对保持分组位置的 Frame 布局。一般局部选区的中间通道绕行仍待改进；插口与曲线位置仍为估算，当前案例仍有 6 处遮挡估算提示，不保证复杂图完全无遮挡。主要验证环境为 macOS / Blender 5.2.2。

## English

Fix small node movements breaking existing alignment and spacing when arranging an enclosing Frame containing multiple child Frames.

- Preserve existing rows, peer columns and consecutive equal gaps in structural layout and constrained fallback.
- Retain the original top-left envelope during fallback, and allow adjacent cards to join an existing aligned row instead of scattering the group to shorten wires.
- Distinguish peer columns from serial computation stages so vertical serial stacks can still arrange left to right.
- In “Estimate merge distance”, maximum movement falls from about 141.76 to 34.40 canvas units. All three Frames stay in place and the terminal card joins the existing row.

### Validation

Passed 108 unit tests, 12 Blender 5.2.2 GUI layout checks, three Frame-selection cases and registration/unregistration checks. A copy of the reported 617-node tree shows no accumulated drift across ten invocations and zero undo/redo error. Logical links, parenting, visible selection and nodes outside the selected Frame remain unchanged.

### Installation and limitations

Install the **Smart_Align_Nodes_v1.0.1.zip** asset from disk through Blender's add-on preferences. After manually replacing an older installation, save your work and restart Blender to load the update.

This patch targets anchored Frame-group layouts. General partial-selection corridor routing still needs improvement. Socket and curve coordinates remain estimates; this case still reports six estimated wire obstructions. The primary validation environment is macOS / Blender 5.2.2.
